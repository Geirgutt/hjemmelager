# Hjemmelager

En mobilvennlig Home Assistant add-on for varer, gjenstander, handleliste, bilder,
strekkoder og NFC-tags. Dataene lagres lokalt i Home Assistant, og komplett backup
og lesbar CSV-eksport er tilgjengelig fra appen.

Planen videre ligger i [../ROADMAP.md](../ROADMAP.md), og dokumentasjonen ligger
i [DOCS.md](DOCS.md).
